# **App Name**: MediaBucket

## Core Features:

- Authentication: Secure user authentication system with sign-up and sign-in functionality.
- Image Upload & Management: Dashboard to upload images and store them with associated metadata.
- URL Generation: Generate a direct, shareable URL for each uploaded image.

## Style Guidelines:

- Primary color: Neutral gray (#F0F2F5) for a clean background.
- Secondary color: White (#FFFFFF) for content containers to create separation.
- Accent: Teal (#008080) for buttons, links, and interactive elements.
- Clean, simple layout with a focus on ease of navigation.
- Use simple, clear icons to represent actions and categories.
- Subtle transitions and animations to enhance user experience.
